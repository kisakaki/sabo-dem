モデルの構成と仮定
  • 粒子：円板の並進・回転を2次元で解き、質量・慣性モーメント・流体力は同径の球として評価する擬似2次元モデル。
  • 較正：μ=0.8、μ_r=1.5 で、勾配 6°・8°・10° の平衡濃度が高橋の式（φ≈26°）と一致（例：6° で C̄=0.17、式 0.166）。河床の安定限界は約13.6°。清水の掃流砂量は τ*=0.08〜0.2 で MPM 式の 0.4〜1.6 倍。
  • 接触：法線は線形ばね＋ダッシュポット（反発係数eから減衰を設定）、接線はCundall–Strack型ばね＋クーロン摩擦（μ）、転がり抵抗は弾塑性ばね型（Ai et al., 2011：k_r = 2.25k_nμ_r²R_r²、上限 μ_r R_r F_n）。接触の初回発生時の法線相対速度を衝突速度として記録。
  • 流体：混合距離の積分は河床面 z_b から始め、固相率は1粒径幅で平滑化。河床直交方向の1次元運動方程式 ρε∂u/∂t = ∂z[ρε(ν+ℓ²|∂u/∂z|)∂u/∂z] + ρεg sinθ − Σβ(u−u_p) を陰解法で解く。混合距離 ℓ は固相率で減衰（河床内は ℓ→0 で浸透流）。粒子が受ける抗力の反作用を流体に戻す双方向連成。
  • 流体力：抗力 C_D=(0.63+4.8/√Re)²、Di Felice の空隙率補正 ε^(2−χ)、揚力 F_L=½ρC_L A(u_T|u_T|−u_B|u_B|)（粒子上下端の相対流速）、浮力は河床直交方向の静水圧勾配、付加質量 0.5ρV。水面をまたぐ粒子は没水面積率で按分。
  • 乱れ：u′/u*=2.3e^(−ξ)、v′/u*=1.27e^(−ξ)（ξ=(z−z_b)/h）を標準偏差とするOU過程を粒子ごとに与え、抗力・揚力に反映。
  • 河床の生成：粒子を一粒ずつ既存粒子の上に落とし、2点で支えられる位置まで転がして置く逐次堆積（Visscher–Bolsterli 型）で初期配置を作る。その後、流れ開始後と同じ力のつり合い（法線方向に水中重量、斜面方向に全重量＋河床面に平行な浸透流の抗力 ρVg sinθ(1−C*)/C*）の下で沈降させ、局所減衰で静止させる。平均速度が下がりきらない場合は、勾配が河床の安定限界を超えている可能性を表示。
  • 深部の休止：河床面から 12d より深く 0.05 s 間の変位が 0.02d 未満の粒子を剛体扱い（流体との抗力は計算を続ける）。河床面が 9d まで近づく、または注目粒子の 4d 以内に入ると再び動ける。
  • 境界：流下方向は周期境界。流れとともに移動する区間を追う見方で、初期濃度 C₀ が平衡より低ければ侵食、高ければ堆積が進む。底面は粒径とすき間にばらつきを持たせた固定粒子列と、その上の約1.5粒径分の固定粒子。水の体積を保存するので、侵食で流砂を取り込むと流動深 h(t) は設定値 h から変化する。
  • 河床面と濃度：z_b＝静止粒子（0.05秒間の変位が 0.1d 未満。河床直下のゆっくりしたクリープは河床側に含む）の総面積／(Lφ_b)。C/C*＝移動粒子面積／(L h φ_b)。φ_b は生成直後の河床の面積充填率。
  • 濃度分布：粒子の断面積を河床面基準の d/4 幅の層ごとに集計し、面積充填率に C*/φ_b を掛けて3次元の体積濃度 C に換算。注目粒子は除く。底面の固定粒子は全粒径 C にだけ含め、粒径区分と粗粒分率からは除く。鉛直分布は時定数 τ の指数移動平均。粒径区分は2粒径では d₁/d₂（境界 √(d₁d₂)）、連続粒度では d₅₀ 未満／以上で、可動粒子の濃度を球体積（∝ d³）の比で細粒・粗粒に振り分ける（p₂ と同じ体積基準）。時空間分布は絶対座標の流体セル（d/4）の固相率を区間平均したもの。
  • 高橋の平衡濃度：C∞＝ρ tanθ /{(σ−ρ)(tanφ−tanθ)}、上限 0.9C*。
  • 限界：側方への粒子移動と3次元的な遮蔽・潤滑力は扱わない。流れは流下方向に一様と仮定し、局所的な剥離や圧力変動は乱れの確率モデルで代替している。
